# 이것만 봐 · ShowOnly

선택한 사진만 잠시 보여주는 iPhone용 프라이버시 뷰어의 SwiftUI 시작 프로젝트입니다.

## 프로젝트 시작

1. Mac에서 이 패키지의 `app/show-only` 폴더를 원하는 `app` 디렉터리 아래에 옮깁니다.
2. `ShowOnly.xcodeproj`를 Xcode에서 엽니다.
3. 프로젝트 Target > Signing & Capabilities에서 본인의 Apple Development Team을 선택합니다.
4. 필요하면 Bundle Identifier `com.example.showonly`를 고유한 값으로 변경합니다.
5. iOS 16 이상 시뮬레이터 또는 iPhone을 선택하고 Run합니다.
6. **Face ID·앱 스위처·집중 모드·사용법 유도는 실제 iPhone 테스트를 권장**합니다.

## 현재 포함된 기능(초기 구현)

- 온디바이스 PhotosPicker 기반 사진 선택(최대 10장)
- 선택한 사진만 전체 화면에서 넘기기 및 확대 보기
- LocalAuthentication을 통한 앱 내부 종료/재개 인증
- 비활성화 전환 시 사진 가림 상태로 변경
- 집중 모드(알림 보호) 및 사용법 유도(앱 이탈 제한) 안내

## 반드시 알아둘 제한

- 이 앱은 홈 제스처나 앱 전환을 직접 차단하지 않습니다. 기기 이동 제한은 iOS **사용법 유도**를 별도로 활성화해야 합니다.
- 카톡 등 다른 앱의 알림 배너는 앱이 직접 막지 않습니다. 사용자가 **집중 모드**를 설정해야 합니다.
- 앱 스위처 미리보기 사진 노출 방지는 실제 iPhone에서 검증이 필요합니다.
- 사용자가 선택한 사진 외에는 접근하지 않으며, 사진을 서버에 업로드하지 않습니다.
- 경쟁 앱의 소스·UI·아이콘 등을 복제하지 않은 독자적인 시작 코드입니다.

## 빌드 상태

이 초기 패키지는 Linux 환경에서 생성되었습니다. **Xcode가 없어 실제 iOS 빌드와 시뮬레이터 실행을 수행하지 못했습니다.** Swift 소스 구문 분석은 별도로 검사합니다.
