# 수동 테스트

- [ ] 사진 1장 선택 후 뷰어 진입
- [ ] 여러 장 선택 후 마지막 사진에서 추가 사진으로 넘어가지 않는지
- [ ] 사진 확대/축소 및 페이지 변경 제스처 충돌 여부
- [ ] 세션 종료 버튼 Face ID 및 암호 대체 경로
- [ ] 인증 실패/취소 시 세션 유지
- [ ] 홈 제스처 → 앱 스위처 썸네일 민감 사진 노출 여부
- [ ] 재진입 시 인증 없이 이미지가 보이지 않는지
- [ ] 카톡 알림 집중 모드 OFF/ON 비교
- [ ] 사용법 유도 시작/종료 확인
- [ ] 백그라운드에서 강제 종료 후 사진 세션 복원되지 않는지
- [ ] 큰 사진 10장 선택 시 메모리 테스트

현재 Linux에서 소스만 준비했으며 모든 항목은 실제 iPhone에서 검증해야 합니다.
