# App Store 스크린샷

- `6.9/01–03.png`: 6.9" iPhone용 1320×2868 (6.5"·6.7" 칸에도 그대로 씀)
- `source/`: iPhone 17 Pro Max 시뮬레이터에서 찍은 실제 앱 화면 (9:41, 배터리 100%)
- `build.py`: 문구와 화면을 합쳐 다시 뽑는 스크립트. `python3 design/appstore/build.py` (Google Chrome 필요, Pretendard는 CDN)

| # | 문구 (보조 문구 없음) | 화면 |
|---|---|---|
| 01 | 사진 보여줄 때, 다른 사진까지 볼까 봐 걱정되나요? | 뷰어 |
| 02 | 보여주고 싶은 사진만 골라서 보여주세요 | 홈 / 선택됨 |
| 03 | 카톡 알림이나 다른 앱으로 이동하는 게 걱정된다면? 보호 설정 방법도 알려드려요 | 보호 가이드 |

집중 모드·사용법 유도는 iOS 기능이라 "앱이 막아준다"가 아니라 "막는 법을 안내한다"로만 쓴다.

사진은 시뮬레이터 기본 샘플 사진이다. 제출 전에 직접 찍었거나 상업적 사용이 가능한 사진으로 다시 찍는다.
